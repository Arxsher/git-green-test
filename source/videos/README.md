# Drop the reels here

Put the downloaded @canwebuildthis videos in this folder, as `.mp4` files.

- Name each file by its post order, newest first, if you can: `01.mp4`, `02.mp4` and so on. If not, any name is fine.
- If you know a video's view count or post date, add it to `index.md` in this folder. A screenshot of the grid in `../screenshots/` also works.
- The GitHub website takes files up to 25 MB each through **Add file → Upload files**. Reels are almost always smaller than that.
